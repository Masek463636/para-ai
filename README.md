# PARA AI v5 — настоящий Gemini-анализ

## Что теперь реально делает Gemini

После 15 вопросов браузер отправляет на `/api/analyze`:
- текст каждого вопроса;
- выбранные варианты Person A / Person B;
- 3 свободных ответа.

**Реальные имена и даты рождения в Gemini НЕ отправляются.**
Они остаются в браузере для интерфейса и локальных астрологических/нумерологических метрик.

Gemini возвращает структурированный JSON:
- общий процент совместимости;
- индекс риска расставания;
- 12 AI-метрик;
- большой портрет Person A;
- большой портрет Person B;
- общий портрет пары;
- подробный разбор каждой кликабельной метрики;
- скрытый premium-разбор;
- индивидуальные реплики ChatGPT / Grok / Gemini / PARA для экранной симуляции.

Если Gemini/API временно не работает, сайт автоматически использует старый локальный анализ, поэтому тест не ломается.

## Куда вставлять API-ключ

Ключ НЕ вставляется в `index.html` и НЕ публикуется в GitHub.

После деплоя на Vercel:

1. Открой проект в Vercel.
2. `Settings` → `Environment Variables`.
3. Добавь переменную:
   - Name: `GEMINI_API_KEY`
   - Value: твой настоящий ключ Gemini
4. Выбери Production (можно также Preview).
5. Save.
6. Сделай Redeploy.

Код сервера забирает ключ так:
`process.env.GEMINI_API_KEY`

## Структура проекта

- `index.html` — весь сайт.
- `api/analyze.js` — защищённый серверный endpoint, который вызывает Gemini.
- `package.json` — настройки Node.
- `vercel.json` — настройки Vercel.
- `.env.example` — пример имени переменной, БЕЗ настоящего ключа.

## Локальный запуск через Vercel CLI (не обязателен)

Создай `.env.local`:
`GEMINI_API_KEY=твой_ключ`

Потом:
`npx vercel dev`

## Модель

По умолчанию используется:
`gemini-2.5-flash`

Если позже захочешь сменить модель, измени строку `MODEL` в `api/analyze.js`.
